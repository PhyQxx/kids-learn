# 题库批量生成设计

## 目标

为 KidsLearn 生成一套可审核、可重复生成、可直接导入的基础题库。题库覆盖中国儿童常见学习阶段和项目已有学科，优先补足练习流需要的大题量内容。

生成结果包括：

- `kidslearn-server/sql/question-bank/questions.seed.json`
- `kidslearn-server/sql/question-bank/seed_question_bank.sql`
- `kidslearn-server/sql/tools/generate-question-bank.mjs`

## 范围

题库组合为：

- 学科：语文、数学、英语、逻辑、科学、音乐
- 年级：幼儿园小班、幼儿园中班、幼儿园大班、小学一年级、小学二年级、小学三年级、小学四年级、小学五年级、小学六年级
- 题型：判断题、填空题、排序题、连线题
- 数量：每个学科、年级、题型组合 20 道

总量为 `6 * 9 * 4 * 20 = 4320` 道题。

不生成选择题和语音题。选择题当前数量已经足够；语音题依赖朗读、跟读、音频资产和语音评测链路，后续单独补。

## 内容原则

幼儿园小班、中班、大班参考教育部《3-6岁儿童学习与发展指南》的精神，重点放在生活经验、语言表达、观察比较、分类配对、节奏感知和简单顺序上，避免小学化和机械刷题。

小学一年级到六年级参考教育部《义务教育课程方案和课程标准（2022年版）》的方向，按年级递进控制难度。题目尽量来自生活、校园、自然和传统文化场景，避免偏题、怪题、成人化表达和含糊答案。

每道题都要满足：

- 题干清楚，儿童能独立理解。
- 答案唯一或明确可判定。
- 解析用鼓励式、简短语言说明关键知识点。
- 同一组合内避免简单换词重复。
- 不包含广告、消费诱导、危险行为、地域歧视、性别刻板或不适龄内容。

## 题型格式

题型编号沿用现有系统：

- `2` 判断题
- `3` 填空题
- `4` 排序题
- `5` 连线题

判断题写入两个选项：

- `optionContent = 正确`
- `optionContent = 错误`
- 正确项 `isCorrect = 1`

填空题写入一个或多个可接受答案：

- 题干用 `____` 标记空位。
- 每个正确答案是一条 `question_option`。
- 所有答案项 `isCorrect = 1`。

排序题按正确顺序写入选项：

- 每个步骤或项目是一条 `question_option`。
- `sortOrder` 表示正确顺序。
- 所有项目 `isCorrect = 1`。

连线题按配对写入选项：

- `optionLabel` 为左侧元素。
- `optionContent` 为右侧元素。
- 每条配对 `isCorrect = 1`。

## JSON 数据格式

`questions.seed.json` 是人工审核入口，也是 SQL 的唯一数据源。每条题目使用自然键，避免直接写死数据库自增 ID：

```json
{
  "subjectCode": "MATH",
  "gradeCode": "PRIMARY_1",
  "questionType": 3,
  "questionContent": "5 比 3 多 ____。",
  "score": 10,
  "timeLimit": 45,
  "analysis": "5 比 3 多 2，可以从 3 往后数到 5。",
  "options": [
    { "optionLabel": "", "optionContent": "2", "isCorrect": 1, "sortOrder": 0 }
  ],
  "tags": ["数感", "比较"]
}
```

支持的自然键：

- 学科：`CHINESE`、`MATH`、`ENGLISH`、`LOGIC`、`SCIENCE`、`MUSIC`
- 年级：`KINDERGARTEN_SMALL`、`KINDERGARTEN_MIDDLE`、`KINDERGARTEN_LARGE`、`PRIMARY_1`、`PRIMARY_2`、`PRIMARY_3`、`PRIMARY_4`、`PRIMARY_5`、`PRIMARY_6`

## SQL 导入设计

`seed_question_bank.sql` 负责把 JSON 中的自然键映射为数据库 ID 后插入：

- 通过 `subject.subject_code` 查 `subjectId`
- 通过 `grade_level.level_code` 或年级名称查 `gradeLevelId`
- 插入 `question`
- 插入对应 `question_option`

SQL 使用事务包裹。为了便于重复导入，生成器在 SQL 前半段删除本批次生成的题目，再重新插入。删除范围仅限生成器使用的 `sortOrder` 区间和指定学科、年级、题型，避免影响管理员手工录入的题目。

生成题目的 `sortOrder` 使用保留区间 `900000` 到 `999999`。具体值按组合和题目序号计算，保证同一题库版本重复生成时稳定不变。管理员手工录入题目不使用这个区间。

如果现有库里缺少某个学科或年级，导入脚本应显式报错或注释提示，不静默插入错误 ID。

## 生成器设计

`generate-question-bank.mjs` 包含三层数据：

- 年级画像：年龄、识字量、抽象程度、建议题干长度、建议限时。
- 学科知识点池：每个学科在每个年级的主题、词汇、概念、情境。
- 题型模板：判断、填空、排序、连线各自的生成规则和答案构造规则。

脚本流程：

1. 枚举所有学科、年级、题型组合。
2. 为每个组合生成 20 道题。
3. 校验题目数量、必填字段、答案数量、正确答案标记和重复题干。
4. 写出 `questions.seed.json`。
5. 从 JSON 写出 `seed_question_bank.sql`。

生成器应保持确定性，不依赖联网服务。需要随机变化时使用固定 seed，保证同一次规则可以得到稳定输出。

## 校验规则

生成脚本必须阻止以下问题写入文件：

- 总题量不是 4320。
- 某个学科、年级、题型组合不是 20 道。
- 判断题不是 2 个选项，或正确项不是 1 个。
- 填空题没有正确答案。
- 排序题少于 3 个项目。
- 连线题少于 2 组配对，或左侧元素为空。
- 同一组合内题干重复。
- 题干、选项、解析为空。

## 测试

添加 Node 测试验证：

- 总题量和每组数量正确。
- 四类题型的结构符合前端和后端约定。
- SQL 中包含事务、题目插入和选项插入。
- SQL 没有 `undefined`、`null` 字符串和未转义单引号造成的语法风险。

运行方式优先沿用项目现有 Node 测试风格。

## 后续扩展

本次只生成基础文本题。后续可以在同一 JSON 源数据上继续扩展：

- 为部分题干、选项、解析补充富文本图片。
- 生成题目语音并回填 rich content speech 字段。
- 为课程、关卡或专项练习建立更细的知识点标签。
- 单独生成语音题。
